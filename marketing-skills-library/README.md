# Marketing Skills Library

A library of 25 reusable Marketing Skills, written as structured prompts you can copy into any AI assistant (Cursor, Claude, ChatGPT) and save as permanent Skills.

## What this library is

A curated set of 25 marketing workflows — from hook writing and email sequences to paid ads audits and churn prevention — each formatted as a complete, reusable prompt with defined inputs, outputs, and rules.

## Who it is for

Founders, solo marketers, and small startup teams who want repeatable, high-quality marketing output without hiring for every specialty.

## How to use each Skill

1. Open `index.md` to browse all 25 Skills grouped by category.
2. Open the category file in `skills/` for the Skill you need.
3. Copy the full prompt from the **Prompt** section.
4. Paste it into your AI assistant and provide the **Required Inputs** when asked.
5. Save the result as a permanent Skill so you can invoke it again later.

## Each Skill is a reusable prompt

Every Skill is written as a self-contained prompt. It tells the AI what to ask you for, what to output, and what rules to follow — including never fabricating proof, metrics, or testimonials.

## Add your brand context first

Before using any Skill, add your own brand context: product description, target audience, brand voice, offers, and proof points. The Skills are deliberately generic so they work for any business — your context is what makes the output specific and usable.
