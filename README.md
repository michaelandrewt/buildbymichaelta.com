# Michael Ta's Personal Website

A personal portfolio site built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

- **Hero**: Introduction and social links
- **Who is Michael?**: Timeline at `/who-is-michael`
- **Theme toggle**: Light and dark mode

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
