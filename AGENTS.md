# AGENTS.md

## Project

This repository is the personal website for **buildbymichaelta.com**.

## Safety

- Only modify files inside this repository.
- Never create a nested `buildbymichaelta.com` folder.
- Never delete files or folders unless the project owner explicitly asks.
- Never run destructive commands like `rm -rf`, `git clean -fdx`, or database reset commands.
- Never edit `.env.local`.
- Never print secrets.
- Keep any API keys server-side only; do not expose secrets to client bundles.

## Verification

After code changes, run the appropriate commands for this repo (for example `npm run lint` and `npm run build`) when they are available.
